# AI Notion 期中專題簡報設計

## 目的

製作一份 10–15 分鐘的期中專題報告，向完全沒有接觸過此專案的聽眾說明：

- 專案想解決什麼問題
- 使用哪些技術，以及每項技術的工作
- 系統由哪些部分組成
- 一份文件如何被處理成 Notion 筆記與複習內容
- Prompt 如何規範 AI 的工作
- 開發各功能時遇過哪些具代表性的 BUG，以及如何處理

簡報必須使用生活化語言。技術名詞第一次出現時，要搭配角色、比喻或可見的資料變化。

## 交付格式

- 可編輯的 PowerPoint 簡報
- 可直接播放或繳交的 PDF
- 16:9 寬螢幕比例
- 約 13 頁

## 觀眾與場合

- 場合：期中專題發表
- 觀眾：沒有接觸過 AI Notion 專案，也不假設具備軟體架構知識
- 報告時間：10–15 分鐘
- 成功標準：觀眾聽完後能用自己的話說明「文件如何一路變成可複習的 Notion 筆記」

## 核心敘事

採用「一份文件的旅程」作為主線。

故事從使用者上傳文件開始，依序經過文件解析、清洗、章節辨識、分段、AI 分析、資料驗證、SQLite 保存及 Notion 發布。技術堆疊與系統架構不獨立堆砌名詞，而是在旅程中說明每個工具為什麼出現。

## 視覺方向

- 主風格：深色科技風
- 背景：深藍黑色
- 主色：青藍色，代表資料流與處理中狀態
- 輔色：綠色，代表通過檢查或完成
- 輔色：紫色，代表 AI 與 Prompt
- 警示色：暖橘或紅色，代表 BUG 與風險
- 標題要大、內文要短，避免畫面像程式管理後台
- 每頁以一個主要視覺為核心，避免大量卡片與細碎資訊
- 流程圖只保留理解系統所需的節點，箭頭語意保持一致

## 看不見流程的呈現方式

清洗、分段與 AI 合併無法直接從程式畫面看見，因此使用「文件 X 光畫面」說明：

1. 清洗：並排呈現原始文字與清洗後文字，標示被移除的頁碼、重複標頭與多餘空白。
2. 分段：把長文件畫成多個「閱讀包」，以共享色帶表示相鄰 Chunk 的重疊內容。
3. 合併：顯示多個閱讀包各自完成分析，最後合併成完整筆記。

實際程式截圖負責證明系統可以運作；X 光示意圖負責解釋畫面背後的處理。

## 截圖規則

- 使用目前程式的真實介面
- 使用示範文件或不具敏感性的操作結果
- 可以保留私人 Notion 頁面內容
- API Key、Token 與其他登入憑證必須遮蔽
- 截圖只保留與該頁重點相關的區域，移除無關瀏覽器或桌面資訊

## BUG 敘事方式

BUG 不集中成冗長的問題清單，而是放在對應功能旁邊。

每個 BUG 使用相同結構：

1. 原本預期什麼
2. 實際發生什麼
3. 最後怎麼處理

預計使用的案例：

- 章節辨識：版本號、日期或小節編號曾被誤判為章節標題
- 文件分段：切點落在句子中間，造成 AI 缺少上下文
- AI 回傳：多出 Markdown code fence、JSON 格式錯誤或缺少必要欄位
- 背景發布：Notion 頁面已建立，但工作狀態仍顯示失敗

不另外安排未來規劃頁，也不把開發問題作為報告主軸。

## 頁面安排

1. 封面：文件進來，知識出去
2. 問題：文件很長、整理很慢、整理完也不一定會複習
3. 核心目標：把文件變成筆記、題目、Flash Card 與可追蹤的複習資料
4. 成果預覽：程式介面、Notion 筆記及練習功能
5. 技術堆疊：每個工具只負責一項最擅長的工作
6. 系統架構：介面、文件處理、AI、資料驗證、SQLite 與 Notion 的關係
7. 一份文件的旅程：完整運作流程總覽
8. 文件清洗與章節辨識：前後對照及誤判 BUG
9. 文件分段：閱讀包、重疊區域及上下文遺失 BUG
10. Prompt 設計：角色、輸入、輸出欄位、限制與合併策略
11. Pydantic 品管關卡：格式驗證及 AI 回傳格式 BUG
12. 發布與保存：Notion、SQLite、背景工作及狀態不同步 BUG
13. 總結：這不是單純呼叫 AI，而是一條可檢查、可重試、可保存的處理線

## 資料正確性

- 內容以目前工作區的程式與 `docs/` 文件為主要依據
- 技術堆疊與流程必須符合目前 v3.2.6 專案
- 不把格式驗證描述成內容真實性驗證
- 不把 SQLite 與 Notion 描述成完全相同的儲存用途
- 不使用真實 API Key 或 Token 作為畫面內容

## 驗證標準

- PowerPoint 每頁均需完整渲染並逐頁檢查
- PDF 需重新渲染成圖片並逐頁檢查
- 不得有文字截斷、非預期換行、物件重疊或無法辨識的截圖
- 系統架構與資料流程的箭頭方向必須一致
- 每個技術名詞均能從頁面上的一句白話說明理解
- 全套內容可在 10–15 分鐘內完成，不依賴講者額外解釋大量背景知識
